# Optional assignment features

## Wishlist
Add a `wishlists` collection with `{ userEmail, studioId, createdAt }`. Add authenticated POST/DELETE endpoints and a heart button on studio cards.

## PDF invoice
After a booking becomes Confirmed, create a PDF receipt containing booking ID, studio title, hourly rate, selected date/time, total amount, host and guest. Use a server-side PDF library and return it as an attachment.

These are optional and intentionally separated from core booking behavior.
